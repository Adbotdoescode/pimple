Problem 2.7: Differentiate a product

Problem set 210 pointsShow every rule you use

Find dydx for the function below. Use the product rule, and show each step.

y = (3x2 + 1) · sin(2x)

3ddx sin(2x) = cos(2x)
4dydx = 6x · sin(2x) + (3x2 + 1) · cos(2x)
