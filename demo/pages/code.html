CS 101 — Exercise 4

Exercise 45 pointsFind the bug, then fix it

This prints 4.666… instead of 6.0. Find the bug.

Code
def average(nums):
total = 0
for i in range(1, len(nums)):
total += nums[i]
return total / len(nums)
print(average([4, 8, 6]))
Output
4.666666666666667
Expected output: 6.0
Your fix
Describe the bug in one sentence, then write the corrected code.
