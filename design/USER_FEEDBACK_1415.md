# User feedback after first real test (14:15) — verbatim intent, organised

DESIGN (Fable works on the design elements):
1. Bubble: far more fluid, dynamic and liquid, like design/liquid-glass-reference/bubble-lens.png
   (a clear lens that magnifies and refracts the content under it, with rainbow/chromatic distortion at the rim).
2. The same liquid-glass language on ALL generated content: whiteboard window, the speech card / panel.
3. Organic bubble shapes; fluid, jiggly motion while dragging (soft body).
4. When idle, the bubble merges into the screen edge like condensed water on glass, left or right.
5. After a drag/lasso, the bubble always moves back to the left or right edge (away from the target)
   so it never covers its own explanation.
6. Diagrams: varying line thickness, different textures, more fluid/organic shapes, more beautiful.
7. Every text label gets a small translucent glass pill behind it for readability on any background.
8. A marker / pencil tip that travels along each line while it is being drawn.
9. Panel: add minimise and close buttons, and a forced "shut up" (stop talking now) control.

FUNCTION:
10. Interrupt at ANY moment (thinking, verifying, drawing, speaking, checking), not only while speaking.
11. Remove the "I'm looking at …, what do you want to ask?" summary on drag/lasso. Just listen.
12. Drag/lasso: the circled area is the main focus, but ALSO send a full-screen screenshot as context.
13. If the screen does not contain enough to answer the question, automatically open the whiteboard window
    and draw from scratch there (still using the screenshot as context).
